Experimental and Theoretical Analysis of Matrix Addition, Transpose, and Multiplication (SVNIT M.Tech CSDS103)

Execution Time vs Matrix Size Plot

Theoretical vs Experimental Complexity Breakdown

Matrix Addition (O(n²))

  • Scalar Operations: Exactly $n^2$ additions and assignments.
  • Scaling Factor: Doubling dimension (e.g. $50\times50 \to 100\times100$) increases time by $\approx 4\times$.
  • Observed Latency: Scales smoothly from ~0.003 ms ($10\times10$) to ~3.5–5 ms ($500\times500$).

Matrix Transpose (O(n²))

  • Scalar Operations: Exactly $n^2$ element indexing assignments ($T[i][j] = A[j][i]$).
  • Cache Behavior: Direct quadratic access pattern with low memory overhead.
  • Observed Latency: Executes within ~0.002 ms ($10\times10$) up to ~3.5 ms ($500\times500$).

Matrix Multiplication (O(n³))

  • Scalar Operations: $n^3$ multiplications and $n^2(n-1)$ additions.
  • Scaling Factor: Doubling dimension increases operations by $2^3 = 8\times$. $10\times$ dimension increase yields $1000\times$ latency.
  • Observed Latency: Escalates steeply from ~0.007 ms ($10\times10$) to ~1,000–1,200 ms ($500\times500$).
